# Wings of Fire Search

A Manifest V3 Chrome extension that replaces the New Tab page with Wings of Fire Search.

## Install from the ZIP

1. Download `WingsOfFireSearch-Chrome-Extension.zip` from this repository.
2. Extract it to a permanent folder.
3. Open `chrome://extensions` in Chrome and turn on **Developer mode**.
4. Select **Load unpacked**, then choose the extracted folder containing `manifest.json`.

The extension needs no special permissions. Open a new tab once it is loaded.
